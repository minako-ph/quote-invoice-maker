# デモ動画撮影台本（sensitive審査提出用）

対象: 「見積書・請求書メーカー for Google Sheets」／想定尺: **3〜4分**（受入基準§9-5「サンプル利用時3分以内」の動線をそのままなぞる）
目的: 4スコープすべての実使用シーンと、OAuth同意画面のスコープ一致を審査員に見せる。
撮影条件: 画面録画（1080p以上・日本語UI）。テスト用Googleアカウントで、**未認可状態から**録る（同意画面を必ず収録するため）。ナレーションは英語字幕を後付けできるよう短い文で。

## 事前準備（映さない）

- テスト用スプレッドシートを新規作成し、アドオンをテストデプロイでインストール可能にしておく
- 発行者プロファイルは**未設定**の状態に戻す（UserProperties初期化）＝初回起動の動線を見せるため
- Driveの「帳票」フォルダを削除しておく（フォルダ自動作成のシーンを見せるため）

## シーン構成

### Scene 1: 起動とOAuth同意（〜0:40）［container.ui／スコープ一致の提示］

1. スプレッドシートを開き、拡張機能メニューから「見積書・請求書メーカー」→「サイドバーを開く」。
2. 初回の権限承認ダイアログを**スクロールも含めて全文映す**。
   - ★審査ポイント: 表示されるスコープが申請どおり4点のみであること（現在のスプレッドシート／外部サービスへの接続／サイドバーUI／このアプリが作成したDriveファイル）。
3. 承認後、サイドバーが開く（container.ui の実使用シーン）。
   - ナレーション例: 「アドオンはサイドバーだけで操作します。要求する権限はこの4点のみです」

### Scene 2: プロファイル設定とサンプル生成（0:40〜1:30）［spreadsheets.currentonly］

1. サイドバーの「発行者プロファイル」を開き、氏名/名称・住所・登録番号（テスト値 T1234567890123）・振込先を入力して保存。
2. 「サンプルで試す」をクリック → サンプル見積書シートが**現在のスプレッドシート内に**生成される。
   - ★審査ポイント: currentonly の実使用（開いているファイルにシートを作成・書き込み）。
   - ナレーション例: 「アクセスするのはいま開いているスプレッドシートだけです」

### Scene 3: 再計算とPDF出力（1:30〜2:20）［external_request（export）／drive.file］

1. 「プレビュー / 再計算」をクリック → 集計ブロックと計算根拠の注記（適用税率・端数処理・源泉税の式）がシートに書き込まれるのを映す。
2. 「PDF出力・Driveに保存」をクリック → 成功メッセージ（ファイル名 `YYYYMMDD_サンプル株式会社_…pdf` とリンク）を映す。
   - ★審査ポイント: external_request は Google のexport APIを利用者自身のトークンで呼ぶだけであること（ナレーションで補足）。
3. 表示されたリンクからDriveを開き、「帳票 → 見積書」フォルダにPDFが保存されていることを映す。
   - ★審査ポイント: drive.file の実使用（アプリが作成したフォルダ/ファイルのみ。既存ファイルには触れない）。
   - ナレーション例: 「保存先はアドオン自身が作成したフォルダだけです。既存のDriveファイルにはアクセスできません」

### Scene 4: 見積→請求変換と2枚目のPDF（2:20〜3:10）［FR-2の一気通貫］

1. サンプル見積書シートに戻り、「見積書 → 請求書に変換」をクリック → 明細・取引先を引き継いだ請求書シートが生成される（支払期限・源泉徴収・振込先が有効）。
2. そのまま「PDF出力・Driveに保存」→ 成功メッセージ。
3. Driveの「帳票 → 請求書」フォルダと、スプレッドシートの「台帳」シート（発行日・種別・番号・取引先・金額・リンクの自動記帳）を映す。
   - ナレーション例: 「見積から請求、PDF、命名保存、台帳記帳までがワンクリックずつで完結します」

### Scene 5: クロージング（3:10〜3:30）

1. サイドバーの使用量表示（「今月の出力 2/3枚」）とヘルプの「できないこと（正直な明記）」を短く映す。
   - ナレーション例: 「無料枠は月3枚。書類の内容が外部に送信されることはありません」

## 撮影後チェックリスト

- [ ] OAuth同意画面の4スコープが判読できる解像度で映っている
- [ ] 4スコープすべての実使用シーンがある（UI表示／シート書き込み／PDF export／Drive保存）
- [ ] 実在の個人情報・実顧客名が映っていない（すべてサンプル値）
- [ ] 尺が5分以内（目標3分台）
- [ ] 動画URL（限定公開YouTube等）を審査フォームに記載
