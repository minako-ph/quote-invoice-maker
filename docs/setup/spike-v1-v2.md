# V-1/V-2 スパイク実行手順（引継書§12-3。人間・テストシートで約10分）

未検証事項 V-1（export URL の4スコープ認可）・V-2（Advanced Drive Service の drive.file 実挙動）を
実機で確定する手順。**結果は必ず docs/decisions.md に1行ずつ記録する**（要件書§9-7 受入基準）。

前提: `docs/setup/clasp.md` の手順で clasp push とテストシートへのインストールが済んでいること
（スパイクはアドオンのスクリプトに同梱済み。`exportPdfProbe` / `driveProbe` がエントリポイント）。

## 手順

1. テスト用スプレッドシートを開き、適当なセル（A1:C5 あたり）に何か値を入れる。
2. 拡張機能 → Apps Script でエディタを開く（デプロイテスト時は、push した standalone
   プロジェクトのエディタを直接開く）。
3. 上部の関数選択で **`exportPdfProbe`** を選び「実行」。初回は権限承認ダイアログが出る
   （**承認を求められるスコープが4点のみであることもここで目視確認**＝CR-3）。
4. 実行ログ（表示 → ログ）を確認する:
   - `HTTP: 200`・`%PDFマジックバイト: OK` → **V-1成立**。
   - `HTTP: 401/403` 等 → **V-1不成立**。ログ全文を控える。
5. 同様に **`driveProbe`** を選んで「実行」し、ログを確認する:
   - `フォルダ作成: OK`・`PDFアップロード: OK`・`取得確認: OK` → **V-2成立**。
     マイドライブに「_v2probe_帳票」フォルダと `_v2probe.pdf` ができていることを目視確認
     （確認後、フォルダごと削除してよい）。
   - 例外発生 → **V-2不成立**。エラーメッセージを控える。
6. `docs/decisions.md` に結果を記録する（例）:
   - `2026-07-XX V-1成立: export URL+OAuthトークンでHTTP 200/%PDF確認（4スコープ・テストシート実機）→ FR-7はexport URL方式で確定`
   - `2026-07-XX V-2成立: Drive v3 Advanced Service（drive.file）でフォルダ作成・PDF保存・取得OK → FR-8はAdvanced Drive方式で確定`

## 不成立時の動き（引継書§6・CR-3）

- **V-1不成立** → フォールバック(1): drive.file でアプリが新規作成したスプレッドシートへ帳票を複製し、
  そのファイルの export URL を叩く方式を試す（スパイクの改修が必要。実装者に差し戻す）。
  それも不成立なら **(2) 停止して人間判断**（スコープ追加・別方式への切替は要件書CR-3の改訂＝事業判断）。
- **V-2不成立** → 同様に停止して報告。**スコープ追加で解決しない。黙って代替しない。**

## 成立後（実装者側の作業）

- V-1/V-2 とも成立していれば、本実装（pdf.ts / drive.ts）は既に同方式で接続済みのため追加作業なし。
  サンプル書類で「見積→請求→PDF→Drive保存」のE2Eを通し、A4レイアウト品質を確認して微調整する。
